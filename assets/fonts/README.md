# Tamil Font Setup

To enable Tamil font rendering, download the Noto Sans Tamil font:

1. Visit: https://fonts.google.com/noto/specimen/Noto+Sans+Tamil
2. Download the font family
3. Extract and copy `NotoSansTamil-Regular.ttf` to this directory

Alternatively, the app will use Google Fonts package to load the font automatically at runtime.

Note: The font file is not included in the repository due to licensing. The app will work without the local font file as it uses google_fonts package as fallback.
