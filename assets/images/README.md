# Image Assets

This directory should contain images for:
- Word illustrations (animals, fruits, colors, etc.)
- App logo
- Achievement badges
- UI elements

Recommended image formats: PNG, JPG, SVG

Example naming:
- `dog.png` - for நாய் (dog)
- `cat.png` - for பூனை (cat)
- `apple.png` - for ஆப்பிள் (apple)
- `logo.png` - app logo

The app will work without images, but they enhance the learning experience for children.
